# D_Sticker Generator

An AI-powered sticker generator created using Google Opal.

## About the Project
D_Sticker Generator is an AI-based application that helps users create personalized sticker concepts using their creative ideas and text prompts.

## Features
- AI-powered sticker generation
- Creative and personalized sticker concepts
- Simple and user-friendly interface

## Technology Used
- Google Opal
- Generative AI
